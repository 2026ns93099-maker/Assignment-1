Constitution
Purpose
Develop a Smart Todo Task Manager that enables users to create, update, delete and track tasks.

Quality Principles
All task operations must work correctly.
Task data must be saved reliably.
Invalid inputs must be handled safely.
Code should be simple and maintainable.
All features must be tested before acceptance.

Success Criteria
Users can add tasks.
Users can update tasks.
Users can delete tasks.
Users can view tasks.
Tasks persist in a JSON file.
Tasks can be filtered by tag.
Tasks can be sorted by priority.
