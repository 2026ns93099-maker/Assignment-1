Specification
Overview
The Smart Todo Task Manager allows users to manage daily tasks.

Functional Requirements
1.FR-1 Add Task
Users should be able to create a task with:
Title
Description
Priority
Tag
2.FR-2 Update Task
Users should be able to modify existing tasks.

3.FR-3 Delete Task
Users should be able to remove tasks.

4.FR-4 View Tasks
Users should be able to view all tasks.

5.FR-5 Filter Tasks
Users should be able to filter tasks by tag.

6.FR-6 Sort Tasks
Users should be able to sort tasks by priority.

7.FR-7 Persistence
Tasks should be saved in a JSON file.

Acceptance Criteria
Task creation succeeds with valid input.
Task update succeeds for existing tasks.
Task deletion removes the task.
Filtering returns matching tasks.
Sorting displays tasks in priority order.
Tasks remain available after application restart.
