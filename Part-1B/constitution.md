Constitution
Purpose
Develop a Natural Language Reminder Agent that converts reminder requests into structured JSON output.

Quality Principles
Outputs must follow the defined schema.
Missing information should trigger clarification.
Invalid requests should be handled safely.
Responses should be structured and predictable.
Evaluation must be performed before acceptance.

Success Criteria
Reminder intent identified correctly.
Task extracted correctly.
Date and time extracted correctly.
Output schema validation passes.
